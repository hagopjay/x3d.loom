# Learnings: Giza VI, five editions merged into one narrative (Babylon.js + X3D twin)

Fold-back from x3d.demo `docs/demos/giza-osiris-hall/v6/` (Giza VI · The Five Witnesses), which merges the v3 Evidence Atlas, the Hawara Witness Atlas v4.1, Giza IV Horizon Engine and Giza V Earth's Tesla Coil, and ships the three uploaded packs beside it as `v4/`, `v4-horizon/` and `v5/`. Measured 18 Nov 2026 in a Linux container: Node 22.23.5, Python 3, headless Chromium 157.0.8103.78 on SwiftShader (ANGLE Vulkan, CPU only), Babylon.js 8.56.2, X_ITE 16.6.0, validator x3d_mcp `fa5dccf`. Grades: **C** run and read here, **L** computed or likely, **S** suspected. Local IDs `G6-n`; renumber on promotion to LOOM-v1.md. Earlier Giza lessons: [GIZA-EVIDENCE-ATLAS.md](GIZA-EVIDENCE-ATLAS.md) (GZ-1 to GZ-12).

| G6-1 | **One geometry source, two renderers.** `world.mjs` is pure (no DOM, seeded RNG); the Babylon page draws it and `build/export_x3d.mjs` writes the X3D twin from the same arrays. The showpiece can use every Babylon trick while the accountable file stays a validated X3D 4.0 scene with a per-Shape grade. | twin rebuild byte-identical; XSD valid, 0 errors, 0 warnings, 65 info | C |
| G6-2 | **Babylon `useRightHandedSystem` keeps clockwise-from-outside faces, and `VertexData.ComputeNormals(..., {useRightHandedSystem:true})` then points them inward.** First render: ground culled; after flipping winding, ground mean normal y was -0.999 and everything looked flat-lit. Fix: no RH flag on ComputeNormals; the X3D exporter swaps two indices per triangle so the file is the default `ccw='true'`. | screenshots + probe; test `winding contract` | C |
| G6-3 | **`CascadedShadowGenerator` drew no shadows in the right-handed scene** (23 casters registered, `shadowEnabled` true, nothing on the ground). A plain `ShadowGenerator` with PCF and `autoUpdateExtends` on the same light drew them at once. Not isolated further (RH, depthClamp or SwiftShader). | Babylon 8.56.2, SwiftShader | C observed, S cause |

## Babylon recipe that worked (for the next showpiece)

PBRMaterial with CPU-baked procedural albedo + normal (RawTexture, ~0.8 s for six sets), SkyMaterial into a 256 px ReflectionProbe as `scene.environmentTexture` (refresh only when the sun moves), DefaultRenderingPipeline (ACES, bloom 0.82/0.42, grain, small chromatic aberration, sharpen, FXAA, DoF indoors), VolumetricLightScatteringPostProcess from a sun sphere, GlowLayer for emissives, GreasedLine for arcs (width in world metres: 1.2 m reads from 300 m, 2.4 m smothered a close shot), point-sprite ShaderMaterial for stars, a custom PostProcess for VISOR (depth + luma Sobel, thermal palette, scan lines) labelled as a look, and a fresnel StandardMaterial for an x-ray shell.
