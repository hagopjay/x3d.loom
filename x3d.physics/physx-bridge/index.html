Standard X3D, real physics

Every scene here is a plain X3D 4.0 file using the RigidBodyPhysics component. A bridge switches off the viewer's built-in engine and runs the same nodes on NVIDIA PhysX 5 (WebAssembly, in a worker), writing the results back as ordinary X3D events. Each demo exports its scene as a standard file. Every control is a button with a keyboard shortcut; press ? on any page to see them all.

Marble Machine

Build a marble run on a pegboard, then run it, race it against the viewer's own engine, record and replay it. 14 piece types · PlaneSensor drag and snap · Inline + IMPORT race Replays are bit-exact across Chromium, Firefox, WebKit and Node.

Physics music box

Set pegs on a turning drum; hammers on hinges fall on tuned bars. Every note is a contact. OrientationInterpolator (kinematic drum) · SingleAxisHingeJoint · CollidableShape.enabled live Every peg gives exactly one note, on its own bar, at 60, 120 and 200 BPM.

Draw-a-domino run

Draw rows on the table, push, and time the toppling wave against real dominoes. PlaneSensor drawing · one RigidBody per domino · sleeping PhysX's wave speed against Larham's measured dominoes (arXiv:1302.3311): friction decides.

Trebuchet vs castle

Tune counterweight, sling and release angle; knock the castle down. Hinged counterweight · BallJoint sling · joints removed from the collection to fire and release Release within a step of the angle asked; Node and browser agree to 0.2 m in 166 m.

Galton board

Pour glass beads through pins and watch a bell curve build; tilt and shake the board. CollisionSensor on the pins · RigidBodyCollection.gravity live Ideal pins are not coins: the bell is wider than binomial, and the pin pitch decides how much.

Stairs of doom

A standard H-Anim humanoid as a PhysX ragdoll: push him down the stairs, score the bonks, replay the best crash. HAnimHumanoid → articulation · HAnimJoint.stiffness live · TNT · power flicker The bridge reads H-Anim's own mass and joint-limit fields; the browser's model matches Node's to 1e-5.

Dummy barrage

Three trebuchets hurl toon crash-test dummies at a castle. Explosive dummies optional (on). three trebuchets · ragdoll swapped in at release · 331 stones Measured in Chromium: 59 % of the castle knocked out by three explosive dummies.
