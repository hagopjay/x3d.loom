# Dynasty Loom hypersphere on Babylon: gap log (8 Nov 2026)

Standing rule: not pixel perfect; log the gaps. Grades: C Confirmed (seen or measured here), L Likely (reasoned), S Suspected. Rig for every render claim: Babylon 9.32.0 WebGPU, SwiftShader, stubbed swap chain, requestAnimationFrame slowed, 960x540, correctness only, no timings; reference X_ITE 16.5.1 (WebGL 2, SwiftShader, full Chromium) on the unchanged v5 page, both with `?ui=none&tier=balanced` and the clocks frozen at 0.25 by the page's own `A.freeze`.

| # | Gap | Grade | Note |
|---|---|---|---|
| G1 | **The tapestry (Loom) view stays on X_ITE.** The page is a hybrid: the hypersphere (the default view) is `<x3d-babylon>` when a WebGPU adapter answers, the tapestry is X_ITE's `<x3d-canvas>`, and without WebGPU both views use X_ITE as before | C | The SAI shim holds one browser and one body. The tapestry also needs PROTO (the `Label` chips), Text with a TTF font, and a second engine instance. The built page therefore ships X_ITE 16.5.1 beside the bundle. |
| G2 | No logarithmic depth. The shaders' `gl_FragDepth` is written as the plain projected depth; the `logDepth` field and the page's `LogarithmicDepthBuffer` option are stored and ignored; Babylon runs a reversed float depth buffer | C | No z-fighting seen at the stops tested (the opaque seed core hides its own glow, as in X_ITE). The real-GPU pass is open. |
| G3 | BlendMode is mapped, not emulated: (ONE, ONE) becomes Babylon's ONEONE and (SRC_ALPHA, ONE) becomes ADD; any other pair draws as the default blend and says so | C | The page's `detect()` finds the node in the reader and takes its additive path (`uBlend` 1, gains 0.5 and 0.7), which is the path the night look needs. Without the mapping the glass drew black (found and fixed). |
| G4 | A textured UnlitMaterial's `transparency` now drives the plate's opacity, and re-applies when an interpolator changes it | C | The brain body drew every portrait plate at full opacity (14 plates visible at once instead of the stop's own). Fixed in body-dl.js; the other bundles do not carry it. |
| G5 | Appearance `alphaMode AUTO` is treated as opaque for the seed core and the armillary, and as the page says for the rest (OPAQUE: fibre cores and sky; BLEND: glow, glass, seed glow, bead) | C | X_ITE decides AUTO itself; these two programs write alpha 1. Without depth write on the core its glow painted over it (found and fixed). |
| G6 | The hidden canvas stops drawing (no layout box, no draw); X_ITE pauses a hidden browser, so does this | C | Timers do not tick while hidden, so a returning view shows the clock where it left it. |
| G7 | The pixel dither and film grain are mirrored (WebGPU window y runs down); smoothstep is written out (`sstep`), because the GLSL calls it with its edges reversed; a square is `x * x` where GLSL used `pow(x, 2.)` of a value that can be negative | C | Same density and look; the two squares were undefined on a negative base. |
| G8 | Multisampling and ContentScale tiers: ContentScale sets Babylon's hardware scaling, Multisampling is stored and ignored | C | The quality tiers still set `uQ` (the raymarch and fbm steps). |
| G9 | X_ITE's frames from the first captures were not a clean reference for the fly-through (under a software GL its flights and idle orbit had not settled). The final set uses the museum look with the idle orbit off and a 10 s settle; all eight shots then compare (28.9 to 37.8 dB) | C | See RECEIPT.md. The night look was compared on four shots only (two of them drifted, see the receipt). |
| G10 | The look constants (the `THEME` block of `const` lines at the head of every fragment shader) are read out of the scene's GLSL by a regular expression at material time and written as WGSL consts, so both looks share one WGSL body | C | A new theme that adds a constant of another type (not float or vec3) would need the regex extended; the build prints the DEFs it ports and fails on an unknown one. |
| G11 | Pointer taps and hover were not driven: selection, focus and the lens were tested through `dynastyNav` (the page's own test surface) | C | The page's picking is its own projection of the camera pose, which is unchanged. |
| G12 | The loader line still says "starting X_ITE"; the "fallback" chip lists the software-adapter note on a software GPU and nothing on a real one | C | Shell text unchanged. |
| G13 | No real-GPU Timing, no Safari or Firefox, Windows Chrome 156 needs chrome://flags/#enable-unsafe-webgpu on the UHD 620 | C | The Timing button is the shared one from the other ports. |
| G14 | The built page carries the family scenes and the AI portraits of the v5 release | C | Nothing private is added by this port; the page was already a private Artifact. Publish only as the v5 release is published. |
